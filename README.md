## [https://legislation.support](https://legislation.support)

Start a legislation profile to bookmark and track legislation.

* Create and share a list of bills you support or oppose ([example](https://legislation.support/jehiah-nyc))
* Tag bills, and filter your view of the list by tag ([example](https://legislation.support/jehiah-nyc?tag=parking)) or by legislature
* View and share sponsorship changes ([example](https://legislation.support/jehiah-nyc/changes)), and get notifications in your RSS feedreader ([example](https://legislation.support/jehiah-nyc/changes.xml))
* View and share color-coded legislation scorecards ranking legislators on how their sponsorships and votes match with your opinions ([example](https://legislation.support/jehiah-nyc/scorecard/nysenate))

One user can create multiple profiles to keep track of different lists of bills (e.g., "climate", "open data", etc.). Each profile can track bills across all supported legislatures, and has its own shareable URL.

Currently supports adding legislation in US Congress, New York State, New York City Council, and other US state legislatures; can import via links from congress.gov, assembly.state.ny.us, nyassembly.gov, nysenate.gov, congress.gov, legistar.council.nyc.gov, intro.nyc, and billtrack50.com.
